# Phase 1 boundaries

## Included
- Separate Streamlit and FastAPI processes.
- YAML project configuration.
- Backend health and project-list APIs.
- Environment-driven configuration.
- Basic automated tests.

## Deliberately deferred
- Enterprise AI agent invocation and KB retrieval (Phase 2).
- Requirement parsing and upload workflow (Phase 4).
- Agent orchestration and clarification workflow (Phase 4).
- Excel generation and export (Phase 5).
- Persistent run history and authentication.

## Legacy CAPL
The new application does not include the previous `Internal_AI` CAPL generation
module or its imports. This starter package is a clean application scaffold.
